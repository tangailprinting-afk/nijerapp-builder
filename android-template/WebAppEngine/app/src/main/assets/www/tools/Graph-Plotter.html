Graphing Reference Guide
Standard Syntax
Use valid mathematical operators for rendering:
x^2 sin(x) sqrt(x) abs(x) log(x) 2*x + 1
Function Transformations
y = f(x) + c : Shifts the graph vertically.
y = f(x - c) : Shifts the graph horizontally.
y = -f(x) : Reflects graph across the X-axis.
y = c * f(x) : Vertically stretches or compresses.
Curve Analysis Concepts
Roots (X-Intercepts): Coordinates where the curve crosses the X-axis (y = 0).
Y-Intercept: Coordinate where curve crosses the Y-axis (x = 0).
