Linear Algebra Rules
Matrix Multiplication (A × B)
The number of columns in A must equal the number of rows in B.
Order matters: A × B ≠ B × A (Not commutative in general).
Determinants |A|
Matrix must be Square (n × n).
If |A| = 0, the matrix is Singular (has no inverse).
2x2 Formula: ad - bc
Inverse Matrix A⁻¹
Matrix must be square and non-singular (|A| ≠ 0).
Formula: A⁻¹ = 1/|A| * Adj(A)
A × A⁻¹ = I (Identity Matrix).
